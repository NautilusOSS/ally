# ARC200 (ACR)

## Boundary

- **ARC200 tokens (wrapped and swap200) are represented in token config with tokenId and type; pool config may reference wrapped pairs and unwrap lists.**
- No direct ARC200 contract calls in the frontend; swap logic and wrap/unwrap are handled by the Swap-API and on-chain contracts.

## Allowed

- Token config entries with type ARC200 or wrapped (e.g. wVOI 390001, wUSDC 395614, UNIT 420069).
- Pool config with `wrappedPair`, `underlyingToWrapped`, `unwrap` for HumbleSwap-style pools.
- Sending token ids and amounts to Swap-API for quote/swap; API returns transactions that may include wrap/unwrap.

## Forbidden

- Calling ARC200 contract methods (transfer, etc.) directly from frontend.
- Building wrap/unwrap transactions in UI.

## Source reference (Ally)

- pools.json: HumbleSwap pools use `underlyingToWrapped`, `wrappedPair`, `unwrap`; Nomadex pool 429995 has tokB type "ARC200".
- config/tokens.json includes 390001 (wVOI), 395614 (wUSDC), 420069 (UNIT).
